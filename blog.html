Finometrics: Predicting & Simulating the Stock Market

Using machine learning to analyze, predict, and act in the Indian stock market

📌 Overview

Finometrics is a full-fledged data science project aimed at demystifying the stock market through machine learning. The project focuses on Reliance Industries Ltd. and includes stock price prediction, market movement classification, and strategic simulation of trading decisions.

🧾 Dataset

  • Source: Real-time data via yfinance
  • Stock: Reliance Industries (RELIANCE.NS)
  • Features: Close Price, Volume, Lag Indicators, Log Returns, Volume Shifts

Methodology

  • Feature Engineering: Lag features, rolling means, log returns
  • Regression: Linear, Decision Tree, Random Forest models
  • Classification: Predicting gain/fall using SVM and Logistic Regression
  • Time Series Forecasting: SARIMA model for multi-step prediction
  • Strategy Simulation: Custom rules to Buy/Sell/Hold with performance charts

📊 Key Results

  • Regression RMSE under ₹10 for daily predictions
  • SARIMA forecasts showed robust pattern learning
  • Trading simulation yielded ~15–20% annualized return (hypothetical)

🔍 Conclusion

While market predictions are never foolproof, Finometrics demonstrates that with the right tools and feature engineering, data science can offer actionable insights. This project showcases the potential of AI in financial analysis and trading strategy development.
